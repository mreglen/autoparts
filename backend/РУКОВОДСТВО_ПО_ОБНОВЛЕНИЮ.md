### Вариант 2: Если Git не работает - ручное исправление файлов

```bash
# Зайдите на сервер
ssh root@195.24.65.251
# Пароль: Vfcnthparol123!

# Перейдите в директорию бэкенда
cd /var/www/autoparts/backend

# Исправление 1: rossko_stock_filter.py
# Добавляем импорт datetime
sed -i '/^import json$/a from datetime import datetime' app/services/rossko_stock_filter.py

# Исправляем функцию _safe_text
sed -i '/return ""$/i\    if isinstance(value, datetime):\n        return value.isoformat()' app/services/rossko_stock_filter.py
sed -i 's/return ""$/return str(value).strip() if value else ""/' app/services/rossko_stock_filter.py

# Исправление 2: cart_delivery_refresh.py
sed -i 's/from datetime import datetime/from datetime import datetime, timezone/' app/services/cart_delivery_refresh.py
sed -i 's/datetime.utcnow()/datetime.now(timezone.utc)/g' app/services/cart_delivery_refresh.py

# Исправление 3: carts.py
sed -i 's/from datetime import datetime/from datetime import datetime, timezone/' app/routers/carts.py
sed -i 's/datetime.utcnow()/datetime.now(timezone.utc)/g' app/routers/carts.py

# Перезапустите приложение
```
