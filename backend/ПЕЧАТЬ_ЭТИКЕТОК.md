# Как настроить идеальную печать этикеток

## 🎯 100% попадание в область печати

### Точная настройка размеров

Для идеальной печати необходимо:

1. **Задать точные размеры этикетки** (в миллиметрах)
2. **Настроить материал страницы** в драйвере принтера
3. **Система автоматически** подстроит печать под область печати

---

## ✅ Автоматическая настройка системы

### Система автоматически определяет область печати!

При указанных размерах этикетки система **автоматически** подстраивается под область печати вашего принтера!

#### Как это работает:

### Шаг 1: Настройка размеров этикетки

1. Откройте **Настройки** → **Печать этикеток**
2. Выберите ваш принтер
3. Укажите **точные размеры** этикетки в миллиметрах:
   - **Ширина (мм)**: например, 58
   - **Высота (мм)**: например, 38
4. Нажмите **Сохранить**

### Шаг 2: Предпросмотр

Проверьте предпросмотр - он отображает указанные вами размеры ({widthMm}×{heightMm}mm).

### Шаг 3: Пробная печать

1. Нажмите **Печать пробной этикетки**
2. Проверьте результат:
   - Этикетка должна печататься четко в области печати
   - Без выхода за границы
   - Без смещений

## 📄 Автоматическая настройка материала страницы

### ❓ Можно ли настроить материал страницы автоматически?

**Да!** Система может автоматически настраивать материал страницы под указанные размеры.

### Как это работает:

В разделе **"Параметры страницы"** → **"Материал для печати"** есть вариант **USER** с настраиваемыми размерами.

#### Вариант 1: Ручная настройка USER

1. Откройте настройки принтера в Windows
2. Перейдите в **Параметры страницы**
3. Выберите **USER** (или "Настраиваемый")
4. Укажите размеры:
   - **Ширина**: равна ширине этикетки из настроек системы
   - **Высота**: равна высоте этикетки из настроек системы
5. Сохраните как preset по умолчанию

#### Вариант 2: Автоматическая настройка (рекомендуется)

**Идеальное решение:**

Создайте **скрипт автоматической настройки**, который при запуске Printer Agent:

1. Получает размеры из `printer_permissions.label_width_mm` и `label_height_mm`
2. Настраивает профиль бумаги в драйвере принтера
3. Применяет настройки автоматически

**Пример реализации:**
```python
import win32print
import win32con

def set_custom_paper_size(printer_name, width_mm, height_mm):
    """
    Автоматическая настройка пользовательского размера бумаги
    
    Args:
        printer_name: Имя принтера
        width_mm: Ширина в мм (например, 58)
        height_mm: Высота в мм (например, 38)
    """
    h_printer = win32print.OpenPrinter(printer_name)
    
    # Получаем текущие настройки
    dev_mode = win32print.GetPrinter(h_printer, 2)["pDevMode"]
    
    # Устанавливаем пользовательский размер
    dev_mode.dmFields = win32con.DM_PAPERSIZE | win32con.DM_PAPERLENGTH | win32con.DM_PAPERWIDTH
    dev_mode.dmPaperSize = win32con.DMPAPER_USER
    
    # Конвертируем мм в единицы принтера (1/10 мм)
    dev_mode.dmPaperWidth = int(width_mm * 10)  # 58mm = 580
    dev_mode.dmPaperLength = int(height_mm * 10)  # 38mm = 380
    
    # Применяем настройки
    win32print.SetPrinter(h_printer, 2, None, dev_mode)
    win32print.ClosePrinter(h_printer)
    
# Использование в Printer Agent
set_custom_paper_size("Your Printer Name", 58, 38)
```

### Преимущества автоматической настройки:

✅ **Точное соответствие** размеров
✅ **Не нужно** настраивать вручную каждый раз
✅ **Автоматически** при смене принтера
✅ **Идеальное попадание** в область печати

### Что нужно сделать:

1. **Добавить функцию** в Printer Agent при старте
2. **Получать размеры** из базы данных (`printer_permissions`)
3. **Применять** к выбранному принтеру
4. **Сохранять** как профиль по умолчанию

### Формула определения области печати

```python
# Printer Agent определяет область печати принтера
page_w = dc.GetDeviceCaps(HORZRES)  # Доступная ширина в пикселях
page_h = dc.GetDeviceCaps(VERTRES)  # Доступная высота в пикселях

phys_offset_x = dc.GetDeviceCaps(PHYSICALOFFSETX)  # Отступ слева
phys_offset_y = dc.GetDeviceCaps(PHYSICALOFFSETY)  # Отступ сверху

# Масштабирование этикетки под область печати
img_aspect = img_width / img_height
page_aspect = page_w / page_h

if img_aspect > page_aspect:
    draw_w = page_w
    draw_h = int(page_w / img_aspect)
    x_offset = phys_offset_x
    y_offset = phys_offset_y + (page_h - draw_h) // 2
else:
    draw_h = page_h
    draw_w = int(page_h * img_aspect)
    x_offset = phys_offset_x + (page_w - draw_w) // 2
    y_offset = phys_offset_y
```

### Позиционирование при печати

Этикетка автоматически позиционируется в области печати:

- **Центрирование**: Этикетка центрируется относительно непечатаемых полей
- **Пропорции**: Сохраняются исходные пропорции
- **Масштабирование**: Автоматически подбирается оптимальный размер

## 🆘 Troubleshooting

### Этикетка печатается со смещением

**Решение:**
1. Проверьте, чтобы в настройках принтера Windows был выбран правильный размер бумаги
2. Убедитесь, что принтер поддерживает landscape ориентацию
3. Проверьте, что драйвер принтера установлен корректно
4. Перезапустите Printer Agent

### Этикетка не помещается целиком

**Решение:**
1. Система должна автоматически уменьшить этикетку
2. Проверьте, что выбран правильный принтер
3. Перезапустите Printer Agent
4. Если проблема сохраняется - обратитесь в поддержку

### Печать выходит за границы

**Решение:**
1. Проверьте настройки полей в драйвере принтера
2. Убедитесь, что используется правильный режим печати
3. Проверьте, что тип бумаги настроен верно
4. Перезапустите Printer Agent
