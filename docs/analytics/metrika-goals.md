# Цели Яндекс.Метрики

Счётчик: **107023580** (`svoygarage.ru`).

## Создание целей в интерфейсе Метрики

1. Откройте [Метрику](https://metrika.yandex.ru/) → счётчик **107023580** → **Настройки** → **Цели**.
2. Для каждой цели выберите тип **JavaScript-событие** и укажите идентификатор:

| Название в UI | Идентификатор (`reachGoal`) | Когда срабатывает |
|---------------|----------------------------|-------------------|
| Просмотр карточки | `part_view` | Открыта страница `/part/...` |
| В корзину | `add_to_cart` | Успешное добавление б/у или новой запчасти |
| Показать телефон | `show_phone` | Нажатие «Показать телефон» на карточке |
| Чат | `chat_start` | Успешное создание/открытие чата с продавцом |
| Заказ оформлен | `order_placed` | Успешное оформление заказа (б/у или new) |

Код отправки: [`frontend/my-autoparts/src/utils/metrikaGoals.js`](../../frontend/my-autoparts/src/utils/metrikaGoals.js) и [`siteAnalytics.js`](../../frontend/my-autoparts/src/utils/siteAnalytics.js).

## Сегменты Organic / Direct

В Метрике:

- **Organic** — стандартный сегмент «Переходы из поисковых систем» или условие: источник содержит `yandex`, `google`, `bing`.
- **Direct** — сегмент «Прямые заходы» (пустой referrer).

Те же классификации дублируются во внутренней аналитике (**Админ → Аналитика → Конверсии → Источники**).

## Celery beat (ежемесячный разбор запросов)

Запуск 1-го числа в 03:00 UTC (08:00 Екатеринбург):

```bash
celery -A app.celery_app beat --loglevel=info
celery -A app.celery_app worker --loglevel=info
```

Задача: `analytics.run_monthly_query_review`.

Ручной пересбор: **Админ → Аналитика → Итерации → Обновить сейчас**.
