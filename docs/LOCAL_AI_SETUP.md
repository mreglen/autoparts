## Оптимизация производительности

### Если модель работает медленно

1. **Уменьшите contextLength** в config.json:
   ```json
   "contextLength": 16384  // вместо 32768
   ```

2. **Отключите индексацию директории**:
   ```json
   "contextProviders": {
     "open": true,
     "directory": false,  // отключить
     "githubIssues": false,
     "googleSearch": false
   }
   ```

### Если не хватает памяти

Модель 14B требует больше памяти. Если тормозит, переключитесь на 7B:
- Отредактируйте config.json
- Замените `"model": "qwen2.5-coder:14b"` на `"model": "qwen2.5-coder:7b"`

## Типичные проблемы и решения

### Continue не подключается к Ollama

**Решение:**
```powershell
Invoke-WebRequest -Uri http://localhost:11434/api/tags -UseBasicParsing
```
Если не работает - перезапустите Ollama

### Контекст переполняется

**Решение:**
1. Используйте `/clear` в Continue
2. Указывайте конкретные файлы вместо "всего проекта"
3. Уменьшите contextLength в config.json

### Модель делает ошибки в коде

**Решение:**
1. Уменьшите temperature до 0.1
2. Дайте более детальный промпт с примерами
3. Попросите модель сначала прочитать файлы, затем писать код

## Рекомендации по работе с локальной моделью

### Что модель делает хорошо

1. **Рефакторинг** - переименование, изменение структуры
2. **Объяснение кода** - что делает этот код
3. **Написание тестов** - unit tests, интеграционные тесты
4. **Следование паттернам** - если показать примеры
5. **Исправление ошибок** - если указать строку и проблему

### С чем модель может справляться хуже

1. **Архитектурные решения** - требует большого контекста
2. **Многопоследовательные задачи** - лучше разбивать на этапы
3. **Поиск по всему проекту** - требует чтения множества файлов

### Лучшие практики

1. **Работайте поэтапно** - разбивайте задачи на маленькие шаги
2. **Очищайте контекст** - `/clear` между этапами
3. **Указывайте файлы явно** - `/file path/to/file` вместо "посмотри проект"
4. **Проверяйте diff** - после каждого изменения
5. **Тестируйте** - запускайте код после изменений
6. **Сохраняйте прогресс** - git commit после каждого этапа
