# Контент для редизайна «Свой Гараж»

## Tone of voice
- Короткие конкретные фразы: действие + объект.
- Избегать: «экосистема», «прозрачные продавцы», «в одном решении».
- Предпочитать: «Найти по артикулу», «Написать продавцу», «Оформить заказ».

См. также `src/utils/brandCopy.js`.

## Фотолист (реальные съёмки)
Нужны фото в WebP/AVIF + JPEG fallback, горизонталь 1600×900 и квадрат 1200×1200:

1. Полки склада с деталями крупным планом
2. Процесс упаковки / этикетка
3. Автомобиль в сервисе / на подъёмнике
4. Рабочее место с запчастями на столе
5. Крупный план типовой детали (фильтр, колодки, фара)
6. Команда / приёмка (по желанию)

Размещение: `public/img/brand/` (создать при появлении файлов).

## Иллюстрации
Готовые SVG-компоненты: `src/components/illustrations/BrandIllustrations.jsx`
- EmptySearch, EmptyGarage, EmptyOrders, SuccessCheck, ErrorWarn

Использовать в `EmptyState` и пустых экранах кабинета.
