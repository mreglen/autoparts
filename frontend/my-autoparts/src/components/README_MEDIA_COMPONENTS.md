# Документация компонентов галереи медиа

## Обзор

В проекте используются три компонента для работы с медиафайлами (фотографиями и видео):

1. **PhotoThumbnail.jsx** - Компонент миниатюр
2. **PhotoGallery.jsx** - Компонент галереи с навигацией
3. **ImageModal.jsx** - Модальное окно для просмотра медиа

---

## 1. PhotoThumbnail.jsx

### Назначение
Компонент отображает **миниатюры фотографий и видео** в виде сетки небольших превью (20x20 или 24x24 пикселей в зависимости от устройства).

### Основные функции

#### Отображение медиа
- **Фотографии**: Показывает изображения в виде миниатюр
- **Видео**: Показывает видео с иконкой play поверх превью
- **Автоматическое определение типа**: Компонент сам определяет, является ли файл видео по:
  - Расширению файла (.mp4, .avi, .mov, .webm и др.)
  - URL (/uploads/videos/)
  - MIME типу (video/*)

#### Интерактивность
- **Клик по миниатюре**: Открывает модальное окно просмотра на выбранном медиа
- **Hover эффект**: Плавное изменение прозрачности при наведении
- **Иконка video**: Для видео отображается полупрозрачная иконка play

### Технические особенности

```javascript
// Объединение photos и videos в единый массив allMedia
const allMedia = React.useMemo(() => {
  const photoItems = (photos || []).map(photo => ({
    type: 'photo',
    item: photo,
    url: typeof photo === 'string' ? photo : (photo.full_url || photo.photo_url || '')
  }));
  
  const videoItems = (videos || []).map(video => ({
    type: 'video',
    item: video,
    url: typeof video === 'string' ? video : (video.full_url || video.video_url || '')
  }));
  
  return [...photoItems, ...videoItems];
}, [photos, videos]);
```

### Где используется
- Страница деталей запчасти (`PartDetail.jsx`)
- Карточки товаров в разделе б/у запчастей (`AutoParts`)
- Списки товаров для быстрого просмотра медиа

### Пример использования
```jsx
<PhotoThumbnail 
  photos={part.photos || []} 
  videos={part.videos || []}
  onImageClick={(allPhotos, initialIndex) => {
    handleImageClick(allPhotos, initialIndex);
  }} 
/>
```

## 2. PhotoGallery.jsx

### Назначение
Компонент для **отображения одной основной фотографии/видео** с возможностью переключения между несколькими медиафайлами и функцией выбора для удаления.

### Основные функции

#### Навигация
- **Большое основное изображение**: Показывает текущее медиа (400px ширина)
- **Кнопки переключения**: Стрелки ‹ и › для переключения между фото/видео
- **Счетчик**: Индикатор текущего элемента (например, "3 / 5")
- **Миниатюры**: Сетка превью внизу для быстрой навигации

#### Управление медиа
- **Просмотр видео**: Видео воспроизводятся прямо в галерее с иконкой play
- **Переключение типов**: Автоматически определяет и корректно отображает фото и видео
- **Выбор для удаления**: Чекбоксы на миниатюрах для множественного выбора

#### Функционал удаления
- **Одиночное удаление**: Кнопка удаления для одного фото
- **Множественное удаление**: Выбор нескольких фото через чекбоксы
- **Удаление выбранных**: Кнопка для удаления всех отмеченных элементов

### Технические особенности

```javascript
// Определение типа медиа
const isVideo = (item) => {
  if (typeof item === 'string') {
    return item.toLowerCase().endsWith('.mp4') ||
           item.toLowerCase().endsWith('.avi') ||
           // ... другие расширения
           item.includes('/uploads/videos/') ||
           item.includes('video/');
  }
  // Проверка для File объектов и других форматов
};
```

### Где используется
- Страница редактирования запчасти (`EditPart.jsx`)
- Страница добавления запчасти (`AddPart.jsx`)
- Формы загрузки/редактирования товаров

### Пример использования
```jsx
<PhotoGallery
  photos={[
    ...existingPhotos.map(photo => ({
      id: photo.id,
      photo_url: photo.photo_url,
      full_url: photo.full_url
    }))
  ]}
  onImageClick={(allPhotos, initialIndex) => {
    handleImageClick(allPhotos, initialIndex);
  }}
  selectedPhotos={selectedPhotosForRemoval}
  onPhotoSelect={handlePhotoSelectionToggle}
  onDeletePhoto={handleDeleteSinglePhoto}
/>
```

## 3. ImageModal.jsx

### Назначение
**Полноэкранное модальное окно** для детального просмотра фотографий и видео с расширенными функциями зума и навигации.

### Основные функции

#### Просмотр медиа
- **Полноэкранный режим**: Затемненный фон на весь экран
- **Поддержка видео**: Видеоплеер с элементами управления
- **Поддержка фото**: Изображения с высоким качеством
- **Автоматическое определение**: Распознает тип медиа и выбирает правильный рендер

#### Зум и навигация
- **Зумирование**: 
  - Кнопки + и − для увеличения/уменьшения
  - Клик по изображению для переключения зума
  - Двойной тап на мобильных
  - Перетаскивание при увеличении
  
- **Навигация**:
  - Кнопки ‹ и › для переключения
  - Клавиши ← и → на клавиатуре
  - Свайпы влево/вправо на мобильных
  - Миниатюры снизу для быстрого перехода

#### Мобильная адаптация
- **Touch события**: Поддержка свайпов для навигации
- **Drag & Drop**: Перетаскивание увеличенного изображения пальцем
- **Оптимизированный UI**: Адаптивные кнопки и инструкции

### Технические особенности

```javascript
// Обработка свайпов
const handleSwipeEnd = () => {
  const deltaX = swipeCurrent.x - swipeStart.x;
  const minSwipeDistance = 50;
  
  if (Math.abs(deltaX) > minSwipeDistance) {
    if (deltaX > 0) {
```

### Управление памятью
- **Object URLs**: Автоматическое создание URL для File объектов
- **Очистка памяти**: Автоматическое удаление ObjectURL при закрытии
- **Предотвращение утечек**: Cleanup в useEffect

### Где используется
- Открывается из `PhotoGallery` при клике на основное изображение
- Открывается из `PhotoThumbnail` при клике на миниатюру
- Открывается из карточек товаров (`ProductCard`)
- Любые места, где нужен полноэкранный просмотр

### Пример использования
```jsx

  onClose={() => setImageModalOpen(false)}
```

## Взаимодействие компонентов

### Типичный сценарий использования

```
1. Пользователь видит товар с миниатюрами
   ↓
2. Кликает на миниатюру в PhotoThumbnail
   ↓
3. Открывается ImageModal на весь экран
   ↓
4. Может листать свайпами/стрелками
   ↓
5. Может увеличить зумом детали
   ↓
6. Закрывает по Escape или клику на крестик
```

### Редактирование товара

```
1. Пользователь в форме редактирования (EditPart)
   ↓
2. Видит существующие фото в PhotoGallery
   ↓
3. Может удалить фото через чекбоксы
   ↓
4. Может добавить новые фото через кнопку
   ↓
5. Кликает на фото → открывается ImageModal
   ↓
6. Рассматривает детали в полном размере
```

## Общие возможности всех компонентов

### 1. Автоматическое определение типа медиа
Все три компонента используют единую логику определения:
- **По расширению**: .mp4, .avi, .mov, .webm, .mkv и др.
- **По URL**: Содержит '/uploads/videos/' или 'video/'
- **По MIME типу**: `file.type.startsWith('video/')`
- **По полям объекта**: `photo_url`, `video_url`, `full_url`

### 2. Поддержка различных форматов данных
Компоненты работают с:
- **Строками**: URL как есть
- **Объектами**: `{ photo_url: '...', full_url: '...' }`
- **File объектами**: Загружаемые файлы
- **Blob объектами**: Бинарные данные

### 3. Оптимизация производительности
- **useMemo**: Кэширование вычислений
- **useEffect**: Правильная очистка ресурсов
- **ObjectURL.revokeObjectURL**: Предотвращение утечек памяти
- **loading="lazy"**: Ленивая загрузка изображений

### 4. Единый стиль обработки видео
- **Иконка play**: Полупрозрачный overlay с иконкой
- **controls={false}**: Скрытые стандартные контролы
- **muted**: Без звука по умолчанию
- **playsInline**: Корректное воспроизведение на iOS

## Заключение

Эти три компонента образуют единую систему для работы с медиа:

- **PhotoThumbnail** - для компактного отображения в списках
- **PhotoGallery** - для управления в формах редактирования
- **ImageModal** - для детального полноэкранного просмотра

Все компоненты поддерживают:
✅ Фотографии и видео

✅ Различные форматы данных
