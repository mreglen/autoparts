# Исправление Push-уведомлений

## Проблемы:

1. ❌ В уведомлении не показывался отправитель (только "Новое сообщение")
2. ❌ При клике на уведомление открывалась страница 404 (неправильный URL)

## Что исправлено:

### 1. Backend - Добавлено имя отправителя в уведомление

**Файл:** `backend/app/routers/websocket.py`

**Изменения:**
- Теперь получаем имя отправителя из базы данных
- Формируем заголовок: `"Новое сообщение от {ИмяОтправителя}"`
- Исправлен URL с `/chat/{id}` на `/chats/{id}` (во множественном числе)
- Добавлены поля `senderId` и `senderName` в push_data

```python
# Было:
"title": "Новое сообщение",
"url": f"/chat/{chat_id}"

# Стало:
"title": f"Новое сообщение от {sender_name}",
"url": f"/chats/{chat_id}"
```

### 2. Service Worker - Улучшена обработка кликов

**Файл:** `frontend/my-autoparts/public/service-worker.js`

**Изменения:**
- Сохраняем `senderId` и `senderName` в данных уведомления
- Исправлен URL по умолчанию с `/chat` на `/chats`
- Улучшена логика открытия окон:
  1. Ищем уже открытое окно с нужным чатом
  2. Если нет - ищем любое окно с `/chats` и отправляем команду навигации
  3. Если нет открытых окон - открываем новое с правильным URL

### 3. Frontend - Обработка навигации из уведомлений

**Файл:** `frontend/my-autoparts/src/index.js`

**Изменения:**
- Добавлен слушатель сообщений от Service Worker
- При получении команды `NAVIGATE_TO_CHAT` создается custom event

**Файл:** `frontend/my-autoparts/src/App.js`

**Изменения:**
- Добавлен компонент `ServiceWorkerNavigationHandler`
- Слушает custom event `navigateToChat` и выполняет навигацию
- Правильно работает даже когда приложение уже открыто

## Как это работает теперь:

### Сценарий 1: Приложение закрыто
1. Приходит push-уведомление: "Новое сообщение от Иван"
2. Пользователь кликает на уведомление
3. Открывается браузер с URL: `https://svoygarage.ru/chats/5`
4. ChatPage загружает чат #5 ✅

### Сценарий 2: Приложение открыто на другой странице
1. Приходит push-уведомление: "Новое сообщение от Иван"
2. Пользователь кликает на уведомление
3. Service Worker отправляет сообщение в приложение
4. App.js получает event и навигирует на `/chats/5` ✅

### Сценарий 3: Чат уже открыт
1. Приходит push-уведомление
2. Пользователь кликает
3. Service Worker находит окно с этим чатом и фокусирует его ✅
